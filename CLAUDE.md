# Inventory Aggregation Service

A .NET service that reads records from the Inventory API and reports them
grouped by category. See `README.md` for setup and `GLOSSARY.md` for the terms
used throughout.

## Agent skills

### Issue tracker

Issues and specs live as GitHub Issues on `bushscott/inventory-aggregation-service`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`. Before closing any ticket, pass both gates in its "Before closing a ticket" section.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root, with any decision records under `docs/adr/`. See `docs/agents/domain.md`.
